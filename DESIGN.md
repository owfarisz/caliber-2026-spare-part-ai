# Interface system

The interface is an enterprise operating workspace inspired by a precise operations ledger: warm light canvas, deep ink navigation, restrained amber signals, and clear data typography. It is meant for planning review, not a dark control-room visual.

- **Surface:** warm off-white `#f5f3ed`, white panels, ink `#172a36`, muted blue-grey `#5d6e77`.
- **Signals:** amber `#d4832f` for review, red `#b84c45` for shortage, green `#2d7662` for within-policy. Color always has a text label.
- **Type:** system sans for rapid scanning; tabular numerals for metrics and tables. Big headings use weight and spacing rather than decorative effects.
- **Layout:** compact left rail on desktop, top navigation on mobile; generous canvas width, aligned charts and tables, no decorative KPI-card repetition.
- **Interaction:** visible focus rings, loading and error states, immediate simulator recomputation, assumption labels beside modeled outputs.
- **Charts:** quantities stay within each material/unit; overview charts count events or materials rather than summing unlike physical units.
- **Narrative focus:** five material stories bridge the full-catalog aggregates to one-material simulations. The green AI decision brief highlights technician-to-inventory handoff and flags policy conflicts.
- **Provenance:** source-derived counts, modeled forecasts, demo vendor ratings and browser-only drafts use distinct labels. The animated insight graph traces joins and effects, while data continuity shows only exception records.
